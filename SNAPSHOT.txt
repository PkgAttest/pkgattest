Re-check the head yourself, offline, without this page:

  pkgattest verify-sth --sth-file sth.json \
                       --log-pub log_ed25519.pub

That proves the head is signed by the key in this directory. It
does NOT prove that key is the log's: compare key_id above against
a value you obtained elsewhere.

What a log entry does and does not say
--------------------------------------
Each entry commits to one PACKAGE (name, version, architecture,
image line, and the digest of its file list). No entry commits to
an image, so 'every package is published' does not mean anyone
published this image -- an image built only from already-published
packages, including a downgrade, would also satisfy it.
